# Fade & Co. Try-On

See the cut on your own face before you book it.

A customer uploads a selfie, tries Fade & Co.'s hairstyles and beard styles on themselves with the YouCam API (Perfect Corp), picks the look they like, and books that exact service at a genuinely free time — through the Chair Ready Voice MCP booking server.

Built for the YouCam API Skin AI & eCommerce VTO Hackathon (Devpost).
